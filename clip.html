第一阶段 · Dual-Encoder Architecture

双塔独立编码与共享特征空间映射

CLIP 不在编码器内部做交叉注意力融合，而是分别将图像切片（Patches）和文本词元（Tokens）编码为特征向量，再通过线性投射层与 L2 归一化映射到同一维度的单位超球面空间。

选择输入图文对：
1. 切片/分词 → 2. 双塔特征提取 → 3. 线性投影与归一化 → 4. 計算余弦相似度
视觉流：Image Encoder (ViT) d_img = 768 → 512

将图像切分为固定大小的 Patch 序列，加上 [CLS] 标记送入 Vision Transformer，提取全局视觉表征 $I_f$，再由投影矩阵 $W_i$ 映射并归一化为单位向量 $I_e$。

语言流：Text Encoder (Transformer) d_txt = 512 → 512

将文本分词并添加 [SOS] 与 [EOS]，通过因果自注意力层提取序列末尾 [EOS] 处的特征 $T_f$，再由 $W_t$ 投射并归一化为 $T_e$。

跨模态融合方式：点积相似度 cos(θ) = I_e · T_e

由于 $I_e$ 和 $T_e$ 都经过了 L2 归一化（长度为 1），它们的点积就等于两向量夹角的余弦值 $\cos(\theta)$。夹角越小，代表图文语义越一致。

第三阶段 · Text-to-Image Referring & Retrieval

推理阶段：文本如何指代整张图像或图像局部区域

训练完成后，无需微调即可直接将任意自然语言编码为文本向量，通过计算与候选图像（或局部区域/Patch 特征）的余弦相似度，实现零样本检索分类与局部物体指代定位。

点击或输入指代文本 Query：

选择要指代定位的图像局部目标：
局部指代原理 (RegionCLIP / DenseCLIP)

当前指代："草地左下角的金毛犬"

原版 CLIP 仅输出整图向量。为了实现用自然语言精准定位图像内部的局部物体，模型将图像划分为网格 Patch 或候选框区域 $R_k$，分别计算每个局部区域向量与指代文本向量 $T_e$ 的点积相似度 $\cos(\theta_k) = R_k \cdot T_e$。
